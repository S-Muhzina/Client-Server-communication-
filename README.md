# Client–Server Communication 
1. Client–Server Communication using TCP
     The client inputs the number of students N and their marks in three subjects. It sends the student details to the server. The server calculates the total, average, and grade of each student and sends the results back to the client. The client displays the processed student details.

2. Client–Server Communication using UDP
     The client inputs two numbers and an arithmetic operator (+, -, ×, /) and sends them to the server. The server performs the specified arithmetic operation and sends the result back to the client. The client displays the result.

3. Client–Server Communication using TCP
     The client inputs an integer N and creates an N × N matrix using random numbers in the range [1,50]. It sends the matrix to the server. The server counts the number of even elements, odd elements, prime numbers, and non-prime numbers in the matrix and sends the counts to the client. The client displays the results.

4. Client–Server Communication using UDP
     The client inputs a sentence from the user and sends it to the server using UDP. The server analyzes the received sentence and determines the number of words, vowels, consonants, digits, and special characters. The server sends the results back to the client, which displays them.
